# Nankai 主项目接入

仿真侧组合外部主项目现有 YOLO、Source/M/W/Servo/RSP；调用原启动、取消和停止服务。场景接入允许固定底座与桌面的安装接触。生成的 SRDF 除固定装配、直接相邻部分的豁免外，还针对当前已确认的安装方式将 `link4`—`sim_d405_bracket` 标为 `Never`，跳过该对的距离减速和接触检查。支架碰撞几何及其他非豁免碰撞对的检查保留；更换支架或安装方式需重新核对，依据见[模型说明](../../models/README.md)。

主项目通过机器配置 main_project 接入，不同步或固定其版本。适配与实验配置留在本仓库。
